Quality Complaints — when the shipment doesn't match the spec

Atraso é uma coisa. Mas às vezes o lote chega — só que fora da especificação. Esta aula cobre o vocabulário de detectar o problema, documentar formalmente, e cobrar uma solução sem parecer nem passivo nem agressivo.

01Detecting the Problem

O caminho que um lote problemático percorre antes de qualquer decisão ser tomada.

fail inspection
→
check the CoA
→
file an NCR
→
quarantine the batch
out of spec — doesn't meet the agreed technical requirements
fail inspection — when quality control catches the problem
certificate of analysis (CoA) — the document that should confirm the batch is within spec
tolerance range — the acceptable margin around the target value
non-conformance report (NCR) — the formal document that records the problem
quarantine the batch — to set it aside so it can't be used by mistake
02Resolving It

Depois de documentar o problema, é hora de cobrar uma solução concreta do fornecedor.

reject the batch
→
request a credit note
→
request a replacement
→
ask for root-cause analysis
reject the batch — formally refuse to accept it
issue a credit note — the supplier's way of refunding without cash changing hands
request a replacement shipment — ask for a new batch that actually meets spec
root cause — the real reason behind the failure, not just the symptom
corrective action — what the supplier will actually change going forward
hold [someone] accountable — to make sure they take responsibility for the failure
In context — Mariana Voss, BioSource
"The Halvorsen batch failed inspection this morning — the purity was outside the tolerance range on their own CoA. I've already quarantined the batch and filed an NCR. We're going to reject it, request a credit note, and ask for a replacement shipment by Friday. But before anything else, I want their root-cause analysis — this can't happen again."
